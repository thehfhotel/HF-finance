แชร์ใบเสร็จจาก iPhone

ตั้งค่าครั้งเดียว ใช้ได้ตลอด — ประมาณ 5 นาที

ทำไมต้องตั้งค่าเอง

iPhone ไม่รองรับให้เว็บแอปแสดงในเมนูแชร์ (Apple ยังไม่เปิดฟีเจอร์นี้) เราจึงใช้แอป Shortcuts ของ Apple แทน ซึ่งทำงานได้เหมือนกัน

Android ไม่ต้องทำอะไร — แค่ติดตั้งแอปจากเบราว์เซอร์ แล้ว "เบิกค่าใช้จ่าย" จะขึ้นในเมนูแชร์เอง

สิ่งที่ต้องเตรียม

ทุกค่าอยู่ในแอปแล้ว ไม่ต้องขอจากใคร — เปิดแอปบนเครื่องเดียวกันนี้ → กล่องขาเข้า → ปุ่มรูปมือถือมุมขวาบน → สร้างรหัสเชื่อมต่อ

จะได้ 4 ช่องพร้อมปุ่ม คัดลอก ข้างละช่อง เปิดหน้านั้นค้างไว้แล้วสลับไปมากับแอป Shortcuts ได้เลย

รหัสเชื่อมต่อ (hfr_…) จะแสดงครั้งเดียว ถ้าปิดไปแล้วยังไม่ได้คัดลอก ให้กดสร้างใหม่ — ของเดิมจะยังใช้ได้ แต่กด "เพิกถอน" ทิ้งได้ ไม่ต้องเสียดาย

ทำมือถือหาย? เข้าแอปแล้วกด เพิกถอน ที่เครื่องนั้น — ใช้ไม่ได้ทันที และไม่กระทบเครื่องอื่น

สร้าง Shortcut

  1. เปิดแอป Shortcuts → กด + สร้างใหม่
  2. กดชื่อด้านบน → Rename → ตั้งชื่อว่า ส่งใบเสร็จ (ชื่อนี้จะขึ้นในเมนูแชร์)
  3. กดไอคอน ⓘ (Details) → เปิด Show in Share Sheet
  4. ในหน้าเดียวกัน กด Share Sheet Types → เลือกเฉพาะ Images และ Files (เอาอย่างอื่นออกให้หมด ไม่งั้น Shortcut จะโผล่ตอนแชร์ข้อความหรือลิงก์ด้วย)
  5. เพิ่มแอ็กชัน Get Contents of URL แล้วตั้งค่าตามด้านล่าง
  6. กด Done

ค่าใน Get Contents of URL

ตั้ง 4 อย่างตามนี้ ไล่จากบนลงล่าง

1. URL — คัดลอกช่องที่ 1 (วางเป็นข้อความ)
https://reimbursement.thehfhotel.org/api/inbox/quick
2. Method
POST
3. Headers — กด "Add new header" 3 ครั้ง
Authorization  →  คัดลอกช่องที่ 2 CF-Access-Client-Id  →  คัดลอกช่องที่ 3 CF-Access-Client-Secret  →  คัดลอกช่องที่ 4
4. Request Body — เลือก File
Request Body: File  ·  File: Shortcut Input
กดที่คำว่า Request Body แล้วเลือก File (ไม่ใช่ Form / ไม่ใช่ JSON) จะมีช่องให้ใส่ค่าเดียว — เลือก Shortcut Input ลงไป

แบบ File ง่ายกว่าแบบ Form เพราะไม่ต้องตั้งชื่อช่อง ไม่ต้องเลือกชนิดของช่อง และมีที่ให้ใส่ Shortcut Input แค่ที่เดียว
จุดที่พลาดบ่อย: ช่อง URL ต้องเป็น ข้อความลิงก์เท่านั้น — ห้ามใส่ Shortcut Input ลงในช่อง URL

ถ้าใส่ผิดจะขึ้น "Shortcuts couldn't convert from Photo media to URL" แก้โดยกดปุ่ม ⓧ ในช่อง URL เพื่อลบออก แล้ววางลิงก์แทน ส่วน Shortcut Input ให้ไปอยู่ที่ Request Body เท่านั้น
เคยตั้งแบบ Form ไว้แล้ว? ใช้ต่อได้ ไม่ต้องแก้ — ระบบรับทั้งสองแบบ แต่ถ้าตั้งค้างไว้ไม่สำเร็จ แนะนำให้เปลี่ยนมาเป็นแบบ File จะง่ายกว่า

วิธีใช้

  1. เปิดรูปใบเสร็จในแอป Photos หรือ Files
  2. กดปุ่ม แชร์
  3. เลื่อนลงหา ส่งใบเสร็จ แล้วกด
  4. เปิดแอป → กล่องขาเข้า → แตะรูป → กรอกจำนวนเงินและหมวดหมู่
ใบเสร็จกระดาษ: ใช้ Notes → กล้อง → Scan Documents จะได้ PDF ที่ตัดขอบและปรับให้ตรงอัตโนมัติ แล้วแชร์ PDF นั้นเข้ามาได้เลย — ระบบแปลงเป็นรูปให้เอง

ถ้าไม่สำเร็จ

  • 401 — รหัสผิด ถูกเพิกถอน หรือลืมคำว่า Bearer หน้ารหัส ให้สร้างรหัสใหม่แล้ววางทั้งก้อน
  • 403 หรือเจอหน้า login — ช่องที่ 3/4 ผิดหรือสลับกัน กลับไปคัดลอกใหม่จากแอป
  • "couldn't convert from Photo media to URL" — เอา Shortcut Input ออกจากช่อง URL (กดปุ่ม ⓧ) แล้ววางลิงก์เป็นข้อความแทน ส่วน Shortcut Input ให้ไปอยู่ในช่อง photo
  • 400 Missing photo — Request Body ยังไม่ได้ตั้ง หรือตั้งเป็น File แต่ยังไม่ได้ใส่ Shortcut Input
  • 413 — ไฟล์ใหญ่เกิน 20 MB
  • 415 — ชนิดไฟล์ไม่รองรับ (ใช้ได้: JPEG, PNG, WebP, HEIC, PDF)
  • ไม่เห็น "ส่งใบเสร็จ" ในเมนูแชร์ — เลื่อนลงสุดแล้วกด Edit Actions เพื่อปักหมุดไว้ด้านบน
